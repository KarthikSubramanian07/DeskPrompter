# Contact DeskPrompter

DeskPrompter is an open-source project maintained by Karthik Subramanian. Support happens in the open on GitHub, so answers help the next person too.

## Questions, bugs and ideas

Open an issue on GitHub: https://github.com/KarthikSubramanian07/DeskPrompter/issues/new

Please include what you were doing, which browser and device you used (for example Chrome on a MacBook, or Safari on an iPhone), and what you expected to happen. If voice mode is involved, say which mode the studio showed: on-device Chrome recognition or the built-in Moonshine model. Never paste a confidential script into a public issue; a short sample that reproduces the problem is enough.

## Security reports

Report vulnerabilities privately through GitHub's security advisories: https://github.com/KarthikSubramanian07/DeskPrompter/security/advisories/new

Private reports are visible only to the maintainer until a fix is released. Please do not open a public issue for a security problem.

## Privacy questions

The privacy page explains exactly what stays on your device and what touches a network: https://deskprompter.pages.dev/privacy. For anything it does not answer, open an issue.

## Contributing

Pull requests are welcome. The repository README describes how the app is built and how to run it locally: https://github.com/KarthikSubramanian07/DeskPrompter
